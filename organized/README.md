# 📱 گزارش کامل و مرتب‌شده‌ی بکاپ سامسونگ

نتیجه‌ی استخراج کامل فایل `samsung.zip` (بکاپ Samsung Cloud).
گوشی: **Samsung Galaxy A03s (SM-A037F)** — اندروید ۱۳ / One UI 5.1 · بکاپ: ۱۴۰۵/۰۸/۰۳

## 📂 فایل‌ها

| فایل | توضیح |
|---|---|
| **`report.html`** | گزارش تعاملی فارسی — با مرورگر باز کنید. خلاصه آماری، تماس‌ها (بر اساس شخص + جدول کامل)، پیام‌ها به شکل **گفتگوی چت**، چیدمان صفحه اصلی، آیکون مخاطب‌های میانبر، تنظیمات و... |
| **`Samsung_Backup_Organized.xlsx`** | اکسل با **۲۴ شیت** راست‌چین و قابل فیلتر |
| `csv/` | همه‌ی داده‌ها به‌صورت CSV تمیز |
| `shortcut_icons/` | ۶۷ آیکون/عکس مخاطب‌هایی که گفتگوشان روی لانچر پین شده بود |

## 📊 خلاصه‌ی داده‌ها

- **تماس‌ها:** ۲۵۰۰ تماس (۱۴۰۵/۰۵/۲۱ تا ۱۴۰۵/۰۸/۰۲) · مجموع مکالمه ≈ ۲۶۳ ساعت و ۱۹ دقیقه
  - ۱۳۹۳ ورودی · ۸۰۰ خروجی · ۲۹۹ از دست رفته · ۸ رد شده
- **پیامک‌ها:** ۱۰۴۰ پیام (۸۱۶ دریافتی / ۲۲۴ ارسالی) در ۵۴ گفتگو
- **مخاطبین:** ۶ مخاطب سیم‌کارت + ۳۶ مخاطب پرارتباط با آمار تماس + ۴ گروه
- **برنامه‌ها:** ۴۴ برنامه با فایل بکاپ APK + فهرست ۶۹ پکیج نصب‌شده
- **باقی:** آلارم، تایمرها، مسدود/اسپم، پاسخ‌های سریع، چیدمان صفحه اصلی (۹۷ آیکون/ویجت/پوشه)، تنظیمات بکاپ و همگام‌سازی ابری، تنظیمات تماس/پیام/مخاطبین/سیستم/تقویم/ساعت/آب‌وهوا، وای‌فای‌ها
