# 📱 گزارش مرتب‌شده بکاپ سامسونگ

این پوشه نتیجه‌ی استخراج و مرتب‌سازی کامل فایل `samsung.zip` (بکاپ Samsung Cloud) است.
گوشی: **Samsung Galaxy A03s (SM-A037F)** — اندروید ۱۳ / One UI 5.1

## 📂 فایل‌ها

| فایل | توضیح |
|---|---|
| **`report.html`** | گزارش تعاملی فارسی — با مرورگر باز کنید. شامل خلاصه آماری، تماس‌ها (گروه‌بندی بر اساس شخص + جدول کامل)، پیام‌ها به شکل **گفتگوی چت**، مخاطبین، آلارم، برنامه‌ها و... |
| **`Samsung_Backup_Organized.xlsx`** | فایل اکسل با ۱۵ شیت راست‌چین و قابل فیلتر |
| `csv/` | همه‌ی داده‌ها به‌صورت CSV تمیز (قابل استفاده در اکسل/پایتون) |

## 📊 خلاصه‌ی داده‌ها

- **تماس‌ها:** ۲۵۰۰ تماس (از ۱۴۰۵/۰۵/۲۱ تا ۱۴۰۵/۰۸/۰۲ — حدود ۲۶۳ ساعت مکالمه)
- **پیامک‌ها:** ۱۰۴۰ پیام (۸۱۶ دریافتی، ۲۱۴+ ارسالی) در ۵۴ گفتگو
- **مخاطبین:** ۶ مخاطب سیم‌کارت + ۳۶ مخاطب پرارتباط با آمار تماس
- **باقی:** آلارم‌ها، تایمرها، لیست مسدود/اسپم، ۴۴ برنامه‌ی نصب‌شده، شبکه‌های وای‌فای، پاسخ‌های سریع پیامک، تنظیمات تقویم/ساعت/آب‌وهوا
